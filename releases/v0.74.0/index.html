Release v0.74.0

Release Date: September 12, 2026

Summary​

v0.74.0 introduces the Composable Demo Run feature — a guided product tour showcasing task execution, Debate and Duel through the real UI with zero data persistence. This release also includes comprehensive OpenTelemetry migration for enhanced telemetry collection and export, significant terminal stability improvements for long-running sessions, and crucial fixes for session recovery workflows.

Major Features​

Composable Demo Run (ADR-0036)​

Complete implementation of a zero-latency, scripted product walkthrough:

  • Demo mode renderer-only seam with gate accessor (readDemoModeEnabled / writeDemoModeEnabled)
  • Settings toggle for demo mode enablement (Sandbox & Terminal tab)
  • Zustand store for reactive demo-mode flag management
  • Full-screen demo tour with navigable segment progression
  • Contextual preview modals for feature exploration
  • Demo segments for:
    • Golden path task execution flow
    • Debate workflow with real agents
    • Duel arm configuration and execution
    • Build With Me Tech Stack Debate feature

OpenTelemetry Migration & Analytics (F1-F4)​

New consent-gated telemetry export pipeline:

  • Bootstrap OpenTelemetry SDK with Grafana Cloud endpoint configuration
  • Consent-gated spans, logs and metrics with per-category granularity
  • Tool invocation telemetry (F2 gate) capturing agent API call patterns
  • Migrated legacy telemetry API keys (F4 move) to secure storage
  • F3 agent environment provisioning for distributed execution contexts
  • Deprecated legacy telemetry sender with graceful fallback

Audit Feature (LLM-Powered)​

New analytics surface for session introspection:

  • Audit tab within project pages
  • Audit run timeline with phase-level metrics
  • Recent audits cross-repo view
  • Task execution audit reports
  • Consent-gated Grafana Cloud integration for audit analytics

Terminal Stability Enhancements​

Critical fixes for production use:

  • PTY Exhaustion: Fixed node-pty memory leak that exhausted macOS PTY table after ~17h of continuous agent activity (native upgrade + streak detection)
  • Session Resume: Fixed crash on fast-failing task resume that corrupted session state

Features & Improvements​

  • Demo Affordances: Global sidebar entry and resource menu button for demo mode access
  • Build With Me: CloudSync sign-up integration in BuildWithMe workflow
  • Activity Tracking: Recent audits aggregation across all project repos
  • Consent Management: Settings UI for OpenTelemetry consent with health indicators
  • Preview Modals: Contextual feature previews accessible from demo segments
  • Terminal Output: LZ4 compression for terminal ring buffers to support longer session histories
  • Session Recovery: Improved state preservation during task-execution failures

Infrastructure & Observability​

  • Telemetry: Event-to-span mapping for OpenTelemetry with semantic attribute preservation
  • Compliance: GDPR-aligned consent gating with per-category export control
  • Monitoring: Exporter health status dashboard integrated into Settings
  • Build: Grafana Cloud OTLP endpoint configuration via environment variables
  • Type Safety: Tri-state isSdkSession tracking across session restore workflows

Bug Fixes​

  • Fixed PTY table exhaustion: Upgraded node-pty from 1.1.0 to 1.2.0-beta.15, added consecutive spawn-failure streak detection as defense-in-depth
  • Fixed fast-failing task resume: Session resurrection no longer overwrites backend state; stale phase cards no longer mask settled phases from prior runs
  • Fixed demo mode gating: Settings key now properly allowlisted enabling demo feature access
  • Fixed terminal session restore: SDK/Codex/CLI sessions now survive page refresh with backend mode preserved

Breaking Changes​

None
