Release v0.7.0

Release Date: January 21, 2026

Summary​

Version 0.7.0 continues to enhance the CrewDeck AI Project Management Platform with significant improvements across terminal interactions, command orchestration, task management workflows, and multi-AI tool support. This release includes 79 feature implementations and 41 bug fixes, delivering a more powerful and user-friendly experience for AI-powered software development teams.

Features​

Terminal and Execution Enhancements​

  • Added minimize/terminate/maximize controls for ongoing terminal operations
  • Implemented interactive Claude terminal sessions with real-time bidirectional input support
  • Enhanced text execution inside the terminal with improved PTY handling
  • Added terminal activity indicator (light) on Kanban board cards
  • Implemented terminal idle notification system to alert users of inactive sessions
  • Changed terminal session naming conventions for better clarity
  • Added visual enhancements to terminal UI components
  • Implemented terminal session scaling for better performance under load

Command and Agent System​

  • Implemented command discovery from repository .claude/commands/ folder
  • Added command chaining for configurable sequential workflow execution
  • Enhanced execute command selection with auto-populated agent assignments
  • Added auto-populate assigned agents when complex command is selected
  • Updated agent discovery for comprehensive command parsing
  • Added skill importing functionality for extensible agent capabilities
  • Implemented agent-only workflow for streamlined task execution
  • Added support for Claude, Cursor, Gemini, and GitHub Copilot AI tools
  • Implemented agent marketplace MVP for browsing and installing agents
  • Added installation/uninstall functionality for agent configurations

Task Management​

  • Added view existing task modal with comprehensive task details
  • Implemented edit ability for tickets in todo status
  • Enhanced task card with additional metadata and visual improvements
  • Added task numbering system with human-readable identifiers (e.g., "ENG-0001")
  • Implemented ability to upload files as task attachments
  • Added task outcome tracking with completion metrics and user ratings
  • Implemented task view optimization for better performance
  • Added easy task review workflow with Review Tasks modal
  • Added terminal launch shortcut to task view modal
  • Added agent selection editing in task view
  • Added ability to edit task scoring after completion
  • Implemented different project ticket creation support

Kanban Board Improvements​

  • Made left side menu departments collapsible
  • Improved Kanban board with enhanced drag-and-drop interactions
  • Done column now displays ticket completion information
  • Changed placement of new task button for better UX
  • Implemented ability to move departments up/down in sidebar
  • Added style updates to Kanban buttons for visual consistency
  • Implemented ability to modify department visibility and settings

Documentation and Configuration​

  • Created comprehensive user guide documentation
  • Added end-user licensing documentation
  • Implemented new Document column for documentation workflow
  • Created standalone HTML functional and technical guides
  • Added DEPARTMENTS.md for external AI agent context
  • Enhanced Claude configuration management (add/remove/generate)
  • Implemented Document Wizard for terminal-free documentation experience
  • Updated user manual with latest features
  • Document workflow now executes with streamlined wizard UI

Release Management​

  • Implemented release management system with version tracking
  • Added release improvement features with better workflow
  • Enhanced process roadmap generation

Analytics and Observability​

  • Added agent observability with real-time tracing
  • Implemented improved analytics dashboard with activity feed
  • Added detailed view for agent traces

Repository and GitHub Integration​

  • Added ability to update PR number on tasks
  • Implemented new repository creation directly from the app
  • Added new types for generating Claude configurations
  • Enhanced repository onboarding wizard with step-by-step guidance
  • Implemented secondary repository connections for cross-project context
  • Added ability to set primary repository for departments
  • Added configurable default GitHub organization for new repositories
  • Implemented refresh button on repos page for syncing

System Improvements​

  • Implemented error recovery system for crash resilience
  • Added test coverage campaign infrastructure
  • Enhanced productivity features across the platform
  • Implemented performance optimizations throughout the application
  • Added GitHub token key documentation and improved setup flow
  • Visual updates to emphasize agentic workflows with agent count display

Bug Fixes​

Terminal Issues​

  • Fixed create task modal not displaying assigned agents for complex workflows
  • Fixed memory leak in terminal sessions with proper PTY cleanup
  • Fixed alignment issue in terminal output display
  • Fixed terminal text alignment problems
  • Fixed unreadable characters posted by terminal
  • Fixed terminal session overflow issues
  • Fixed terminal performance degradation with optimization passes
  • Fixed window maximize behavior affecting terminal layout

Onboarding and Setup​

  • Fixed user creation during onboarding stage
  • Fixed agents command execution during onboarding
  • Fixed first initialization and onboarding flow

UI and Display​

  • Fixed new task modal exceeding screen size
  • Fixed missing task board display on navigation
  • Fixed formatting of GitHub command interface
  • Fixed PR link visibility issues
  • Fixed department name repeated display
  • Fixed deletion confirmation dialog behavior
  • Fixed task view worktree field overflow
  • Fixed department name display in headers

Workflow and Execution​

  • Fixed Claude CLI exit code 1 errors during execution
  • Fixed agent generation issues with empty state
  • Fixed new terminal launch behavior inconsistencies
  • Fixed project navigation issues
  • Fixed auto-transition on build completion
  • Fixed run button todo status state management
  • Fixed document stage Claude execution errors

Performance​

  • Addressed multiple performance improvement requests
  • Documented performance optimization strategies
  • Implemented terminal optimization fixes
  • Fixed performance issues under heavy workload

Data and State​

  • Fixed CI/CD unit test reporting
  • Fixed unit tests failing issues
  • Fixed PR merge widget returning incorrect count
  • Fixed test notification error handling
  • Fixed "Set Primary" repository button not responding

Cleanup​

  • Removed deprecated command agents
  • Removed unnecessary button elements
  • Fixed task rating functionality
  • Fixed project sorting persistence
  • Fixed project ordering on reorder operations

Breaking Changes​

None
