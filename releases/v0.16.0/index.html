Release v0.16.0

Release Date: March 13, 2026

Summary​

Version 0.16.0 is the largest release in CrewDeck history, delivering 342 features and 213 bug fixes across every layer of the application. The release executes a comprehensive platform modernization — upgrading Electron 38 to 40, React 18 to 19, Zustand v4 to v5, xterm.js 5 to 6, and Tailwind CSS v3.4 to v4 — while introducing major new capabilities including task dependencies with visual DAG graphs, Claude Code agent workflow enhancements (thinking levels, turbo mode, MCP tools), a full security hardening campaign with Zod-based IPC validation and BrowserWindow sandboxing, and opt-in anonymous telemetry infrastructure. Terminal performance continues to improve with keyboard shortcuts, session sandboxing, and pause/suspend controls.

Features​

Platform & Dependency Upgrades​

  • Electron 38 to 40 — Major Electron upgrade with Chromium and Node.js updates, verified native module ABI compatibility for better-sqlite3, node-pty, and keytar
  • React 18 to 19 — Upgraded React and react-dom with updated @testing-library/react 14 to 16
  • Zustand v4 to v5 — Migrated all stores to Zustand v5 API across the entire application
  • xterm.js 5 to 6 — Upgraded @xterm/xterm and all addon packages to v6
  • react-router-dom 6 to 7 — Migrated routing with updated API patterns
  • Tailwind CSS v3.4 to v4 — CSS-first configuration with @tailwindcss/vite plugin
  • Vite 7 + electron-vite — Upgraded build toolchain to Vite 7 with electron-vite compatibility verification
  • ESLint 9 to 10 — Upgraded ESLint and eslint-plugin-react-hooks
  • @dnd-kit/sortable 8 to 10 — Drag-and-drop library upgrade with API changes
  • @octokit/rest 20 to 22 — GitHub API client upgrade
  • @electron/notarize v2 to v3 — macOS notarization tooling upgrade
  • electron-toolkit/utils — Upgraded Electron utility packages
  • tar override to 7.6.0 — Security patch for tar dependency

Claude Code Agent Workflow​

  • Thinking level control — Configure thinking depth for task execution to balance speed and quality
  • Effort settings — Adjustable effort levels for Claude Code agent sessions
  • Turbo mode — High-performance mode for increased agent throughput
  • MCP tools configuration — Settings UI for managing Model Context Protocol tool permissions
  • Marketplace skills discovery — Browse and install skills from the marketplace with feature discovery hooks
  • Model tier assignment — Intentional model tier selection (Opus/Sonnet/Haiku) per agent or task
  • Glob-activated rules files — Context-aware rules that activate based on file patterns being edited
  • 5 critical Claude Code hooks — Pre/post execution hooks for agent workflow customization
  • Agent consolidation (40 to 15) — Deduplicated and streamlined agent definitions for clarity
  • Project-specific CLAUDE.md — Per-project Claude Code configuration and settings
  • CLAUDE.md optimization — Restructured to 100-line quick reference with rules file index
  • Planning mode improvements — Enhanced planning mode for complex task orchestration
  • Remove planning mode from UI — Simplified interface after workflow refinement

Task Management​

  • Task dependencies with DAG visualization — Define task dependencies with a visual directed acyclic graph workflow editor
  • Auto-task decomposition — AI-powered automatic breakdown of complex tasks into subtasks
  • Natural language task creation — Create tasks using natural language descriptions
  • VCS-driven task templates — Task templates stored in version control for team sharing
  • Cross-task learning service — Historical pattern injection from completed tasks to improve future execution
  • Intelligent dependencies — Smart dependency suggestion based on task content analysis
  • Task embeddings — Vector embeddings for semantic task similarity and recommendation
  • Epic concept — Grouping tasks into epics for high-level tracking (later removed for simplicity)
  • Removal of epics — Simplified task hierarchy after user feedback
  • Task create UI updates — Improved task creation modal with better agent/command selection
  • Execution replay service — Replay and review past task executions

Terminal Performance & UX​

  • Terminal keyboard shortcuts — Keyboard shortcuts for common terminal operations with visual indicators
  • Terminal sandboxing — Secure sandbox controls for terminal session execution
  • Pause/suspend support — Terminal session pause and suspend with system sleep integration
  • Terminal performance profiler — Built-in profiling for terminal rendering and I/O diagnostics
  • Predictive pre-buffering — Anticipatory data loading for smoother terminal scrolling
  • CircularBuffer class — Memory-efficient buffer implementation for terminal data
  • Terminal padding — Visual padding improvements for terminal edges
  • Scroll-to-top — Ability to scroll to top in terminal sessions
  • Cap per-frame write size — Frame budget enforcement for terminal write operations
  • Decouple xterm.js lifecycle — Separated terminal instance management from React component lifecycle
  • Lazy-loaded xterm.js addons — On-demand loading of terminal addons to reduce initial bundle
  • Direct xterm.js theme integration — Theme colors applied directly without CSS intermediary

Security & Hardening​

  • Zod-based IPC channel validation — Schema validation for all IPC channels at the boundary
  • Content Security Policy hardening — Stricter CSP with subresource integrity
  • BrowserWindow sandbox mode — Enabled Chromium sandbox for renderer processes
  • Chromium renderer sandbox restoration — Re-enabled renderer sandbox after dependency audit
  • Credential access control — Fine-grained access control for stored credentials
  • Security audit logging — Comprehensive audit trail for security-relevant operations
  • Prompt injection pattern detection — Detection and blocking of prompt injection attempts
  • Shell command parameterization — Replaced string concatenation with parameterized commands
  • Path/URL validation — Input validation for file paths and URLs in shell handlers
  • PBKDF2 key derivation — Secure key derivation for credential encryption
  • Allowlist validation — Executable allowlist enforcement in sandbox mode
  • Sandbox executable control lists — Blocked and allowed executable lists for terminal sandboxing
  • Raw GitHub token removal — Eliminated raw token IPC channels in favor of secure alternatives
  • Harden agent discovery pipeline — Security hardening for agent file discovery
  • Harden skip-permissions policy — Stricter policy enforcement for permission bypass
  • npm audit CI gate — Automated vulnerability scanning in CI pipeline
