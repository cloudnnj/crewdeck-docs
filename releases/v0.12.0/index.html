Release v0.12.0

Release Date: February 18, 2026

Summary​

Version 0.12.0 is a major feature and intelligence release focused on task management intelligence, terminal performance, and security hardening. This release introduces a comprehensive task dependency system with DAG validation, AI-powered natural language task creation, auto-task decomposition from epics, intelligent agent selection with confidence scoring, cross-task learning from historical patterns, and failure pattern detection with intelligent retry suggestions. Terminal performance receives significant upgrades including Unix domain socket IPC bypass, binary data transfer, predictive pre-buffering, and proactive memory compaction. Security improvements include a new permission hook system replacing --dangerously-skip-permissions, security audit logging with SQLite event store, and corporate proxy support. The release also adds Team execution mode, pause/resume task execution, git-based team data sharing, and alternative branching strategy support.

Features​

Task Intelligence & AI​

  • Task Dependency System (PR #503) — DAG-validated task dependencies with 3 relationship types (blocks, requires, relates to), cycle detection, and status gating to enforce execution order
  • Task Dependency Types & Metadata (PR #504) — Enhanced dependency edges with type classification, metadata columns, and DAG query support for complex workflows
  • Auto-Task Decomposition (PR #604) — Break down large epics into smaller subtasks using Claude AI, with automatic inter-subtask dependency wiring, parent-child blocking, and quality feedback loop
  • Natural Language Task Creation (PR #577) — AI-powered extraction of structured task fields (title, description, priority, agents) from free-form natural language descriptions with confidence scoring
  • Intelligent Agent Selection (PR #558) — Confidence-scored agent recommendations using hybrid scoring: 60% composite ranking + 40% semantic similarity + user override boost with 30-day decay
  • Cross-Task Learning Service (PR #600) — Historical pattern injection service that learns from past task executions to improve future suggestions, with timer-safe cleanup and security-hardened inputs
  • Failure Pattern Detection (PR #609) — Automatic analysis of terminal output and execution data to detect failure patterns (timeout, missing dependency, agent mismatch, resource exhaustion, permission errors) with intelligent recovery strategy suggestions
  • Task Intelligence & Embeddings (PR #577) — Semantic search using Voyage AI embeddings (voyage-3-lite) with TF-IDF keyword fallback, circuit breaker protection, and budget tracking

Execution & Collaboration​

  • Team Execution Mode (PR #563) — New agent execution mode enabling team-based parallel execution alongside existing sequential and swarm modes
  • Pause/Resume Task Execution (PR #548) — Pause and resume running tasks, allowing agents to be temporarily halted and restarted without losing context
  • Git-Based Team Data Sharing (PR #547) — Share releases and activity summaries across team members via git commits, enabling collaborative project management
  • Export-to-PR Workflow (PR #558) — Export department data and team exports via git worktree-based pull requests for review-gated data sharing
  • Command-Orchestrated Agent Read-Only (PR #576) — Agents assigned through command orchestration are now read-only in task modals, preventing accidental modification
  • Task Execution Guard (PR #547) — Prevent execution of tasks without agents or command assigned, avoiding empty terminal sessions

Terminal Performance​

  • Unix Domain Socket IPC Bypass (PR #596) — Terminal data bypass using Unix domain sockets for lower-latency communication between PTY workers and renderer
  • Binary Data Transfer (PR #564) — Switch terminal data transfer from string encoding to Uint8Array binary format, reducing serialization overhead
  • Predictive Pre-Buffering (PR #600) — Pre-buffer terminal data for tab switches, providing instant content display when switching between terminal sessions
  • Proactive Memory Compaction (PR #576) — Automatic memory compaction for idle terminal sessions, reclaiming V8 heap space during inactivity
  • Terminal Performance Profiling (PR #603) — Infrastructure for profiling terminal pipeline performance with end-to-end latency tracking
  • V8 GC Tuning (PR #621) — Per-process V8 garbage collection tuning flags (--max-old-space-size, --optimize-for-size) optimized for terminal workloads
  • Cap Per-Frame Terminal Writes (PR #559) — Limit terminal write operations per animation frame to prevent UI jank during high-volume output

Security & Reliability​

  • Permission Hook System (PR #622) — Replace --dangerously-skip-permissions flag with @abdo-el-mobayad/claude-code-fast-permission-hook three-tier system: fast approve (safe ops), fast deny (dangerous ops), LLM analysis (ambiguous cases)
  • Security Audit Logging (PR #623) — SQLite event store for security audit logging, tracking all security-relevant events with structured metadata
  • Corporate Proxy Support (PR #630) — SSL/TLS certificate environment variables passed to PTY processes and Electron net.fetch for GitHub API calls, enabling use behind corporate proxies
  • Tool Invocation Telemetry (PR #558) — Track tool invocations with skip-permissions policy telemetry for security analytics
  • App Refresh Protection (PR #591) — Block browser refresh when active terminal sessions exist, preventing accidental process termination
  • Sleep Prevention Investigation (PR #594) — Caffeinate integration investigation for preventing system sleep during long-running tasks

Project & Repository Management​

  • Alternative Branching Strategies (PR #623) — Per-project branching strategy configuration supporting trunk-based, GitFlow, and custom branch patterns
  • Release Workflow Improvements (PR #622) — Abort release when no changes committed, cleanup stale release worktrees, version validation
  • Stale Worktree Cleanup During Release (PR #564) — Release workflow now cleans up all stale task worktrees belonging to included tasks

Agent & Analytics​

  • Agent Performance Enhancements (PR #534) — Success rate trends over time, duration comparison charts, and project-level filtering for agent performance dashboard
  • Enhanced Agent Performance Dashboard (PR #530) — Improved agent performance visualization with category breakdown and failure pattern analysis
  • Execution Replay Service (PR #530) — Record and replay task execution sessions for debugging and training

Documentation & Infrastructure​

  • Updated User Guide — Comprehensive documentation updates reflecting all v0.12.0 features
  • Updated Database Documentation — Current schema and migration patterns documentation
  • Updated Core Components Documentation — 16 new services, 3 stores, and 8 tables documented
  • Updated Core Services Documentation — 11 previously undocumented services added
  • Electron 38 Upgrade (PR #559) — Upgrade from Electron 35 to Electron 38 with updated native module rebuilds
  • Optimized CLAUDE.md — Streamlined AI agent instructions for better context efficiency

Bug Fixes​

  • Fixed PTY spawn failures — Added retry logic with exponential backoff for transient posix_spawnp failures during terminal session creation
  • Fixed debate execution with CLAUDE.md override — Use --system-prompt flag to prevent CLAUDE.md from overriding debate instructions
  • Fixed repo refresh blocking on uncommitted changes — Stash uncommitted changes during repo refresh instead of blocking the pull operation
  • Fixed macOS keychain password loop — Resolved persistent password prompt loop in macOS keychain integration for secure storage
  • Fixed event loop blocking from sync operations — Eliminated synchronous file system operations from the main process event loop
  • Fixed migration failures on fresh databases — Handle missing __drizzle_migrations table gracefully on first-run database initialization
  • Fixed npm audit vulnerabilities — Resolved all 17 npm audit vulnerabilities (5 high, 12 moderate)
  • Fixed console errors from invalid execArgv flag — Removed invalid --optimize-for-size worker thread flag causing startup errors
  • Fixed project page load time — Parallel fetching and deferred syncs reduce project page load latency
  • Fixed step execution display — Current step name now displayed on Kanban cards during command chain execution
  • Fixed ServiceResult unwrapping — Corrected extractFromDescription and GitHub Issues API call sites to properly unwrap ServiceResult<T>
  • Fixed failed tasks in Rate Tasks panel — Exclude failed tasks from the Rate Tasks review panel
  • Fixed terminal resize for unknown sessions — Guard against resize events for sessions that have already been terminated
  • Fixed debate execution timeout — Resolved debates timing out due to incorrect timeout configuration
  • Fixed export action not writing files — Export action now correctly writes files to user-accessible locations via native save dialog
  • Fixed password loop in settings — Resolved unresolved keychain password loop in settings page
  • Fixed pause button inconsistency — Added double-click guard to pause button and normalized state transitions
  • Fixed primary repo refresh errors — Restored original branch before stash pop and fixed double period in warning messages
  • Fixed description extraction failures — Unwrap ServiceResult from extractFromDescription IPC call for natural language task creation
  • Fixed release action menu — Release action menu now correctly executes do-release command after file ordering
  • Fixed rate tasks function — Rate tasks function no longer displays failed tasks for review
  • Fixed app launch wait time — Reduced application startup time with deferred initialization of non-critical services
  • Fixed git add retry after job completion — Added retry logic for transient git add failures that occur after job completion
  • Fixed PAT token for private repos — Pass personal access token to git clone/pull operations for private organization repositories
