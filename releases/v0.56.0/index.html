Release v0.56.0

Release Date: June 20, 2026

Summary​

Version 0.56.0 introduces cloud synchronization infrastructure, advanced cost metrics tracking, comprehensive keyboard shortcuts for faster navigation, a roadmap management system, and critical security and performance improvements. The release brings E2E encrypted cloud sync with AWS integration, detailed LOC (Lines of Code) cost analytics, and an expansive keyboard shortcut system for improved productivity.

Major Features​

Cloud Synchronization & E2E Encryption​

  • CloudCryptoService: Full AES-256-GCM encryption with DEK/KEK hierarchy and HMAC validation
  • CloudAuthService: Cognito-based authentication with secure token storage
  • CloudSyncService: Snapshot-based push/pull with E2E encryption for data synchronization
  • CloudApiClient: HTTP client with retry, backoff, and rate-limiting for cloud API calls
  • Sync Manifest: Tier A/B/C data classification with automatic secret-stripping projections
  • Terms of Use System: Non-dismissible modal gate with fail-closed acceptance flow
  • CloudSync Settings UI: Panel for managing encryption setup and sync preferences

Cost Metrics & Analytics​

  • LocCostMetricsService: Comprehensive service for tracking and calculating LOC-cost metrics
  • LOC Efficiency Cards: Summary cards displaying cost-per-LOC trends and efficiency metrics
  • LOC Cost Breakdown Table: Per-task cost analysis with detailed line-of-code metrics
  • Cost-Per-LOC Trend Chart: Visual trend tracking for cost efficiency over time
  • AI Cost Dashboard Enhancement: Updated savings section with provider comparison focus
  • Cost Metrics Integration: Full integration into the cost dashboard with real-time updates

Roadmap Management System​

  • RoadmapService: Backend service managing roadmap items and dependencies
  • Roadmap IPC Channels: 8 new IPC channels for roadmap operations (list, create, update, delete, etc.)
  • Roadmap Zustand Store: Map-based store with offline support and retry patterns
  • RoadmapBoard Container: Main component for roadmap visualization and management
  • RoadmapItemCard: Individual card component for roadmap items
  • RoadmapFilterBar: Filter controls for roadmap views
  • MilestoneGroup & DependencyArrows: Drag-and-drop sortable milestone groups with SVG dependency visualization
  • ReprioritizePanel: Modal for efficient roadmap item reprioritization
  • Roadmap Navigation Tab: New tab in main navigation for quick access to roadmap views

Keyboard Shortcuts & Navigation​

  • Global Shortcuts: / for search focus, + for task create, Escape to dismiss modals
  • Shortcuts Help Modal: Live help modal (?) showing all available shortcuts
  • ShortcutManager Singleton: Centralized registry and hook system for shortcut management
  • Board Navigation: ←/→ for column navigation, N/F/R for board views
  • Card Navigation: ↑/↓ within column, Enter to open selected card
  • G-Chord Navigation: G+P projects, G+B board, G+S settings, G+A analytics
  • Card Actions: E edit, D delete, A assign, Backspace to archive
  • Card Move Shortcuts: Ctrl+←/→ to move cards between columns with optimistic UI
  • Undo/Redo: Cmd+Z to undo card moves and status changes

Database & Schema Improvements​

  • Cloud-Sync Schema: 3 sidecar tables for sync state management
  • Migration System: Proper versioned migrations with timestamp ordering
  • Database Locations: Dual database support (runtime + development)

Development & Testing Infrastructure​

  • Windows/Linux CI/CD: CI/CD pipeline for cross-platform executable builds
  • Comprehensive Test Suites: Vitest unit and component tests for all major features
  • Window.api Mocking: Fixtures and mock infrastructure for thorough testing
  • Test Coverage: 95%+ coverage on new components and services

Bug Fixes​

Performance & UI​

  • perf: gate idle renderer timers and honor reduced-motion: Reduces idle CPU/battery drain by gating timers and respecting system reduced-motion preferences

Workflow & Template Fixes​

  • feat: Fix missing ID field causing template save validation error: Resolves validation errors during template saves
  • feat: Add PR confirmation screen after Add Resources workflow: Improves UX with explicit PR confirmation
  • feat: Fix 'Too few parameter values' error when running workflow task template: Fixes parameter binding in workflow execution

Security Improvements​

  • terms_of_use_acceptance: Added to settings allowlist with backend validation
  • Security audit: Comprehensive review of settings allowlist changes and data flow
  • E2E Encryption: All cloud-synced data protected with AES-256-GCM encryption
  • Token Storage: Secure credential storage via Electron's safeStorage
  • Sync Manifest Tier System: Automatic secret-stripping for sensitive data

Architecture & Design Decisions​

  • Freeze AWS API Contract: Formalized AWS API contract and E2E crypto design decisions
  • Modularization: Continued separation of concerns across services, stores, and components
  • IPC Pattern: 8 new roadmap channels following established naming conventions (roadmap:list, roadmap:create, etc.)
  • Zustand Pattern: Map-based state management with immutable updates across all new stores
  • Encryption Design: DEK/KEK hierarchy with HMAC validation for comprehensive security

Documentation​

  • LOC Metrics Tracking Plan: Comprehensive planning document for cost metrics implementation
  • API Architecture Docs: Updated to reflect new cloud sync and roadmap services
  • Keyboard Shortcuts Guide: Full reference in live modal and documentation

Breaking Changes​

None

Migration Notes​

Database​

  • Run npm run db:generate -- --name cloud-sync-schema if updating from previous release
  • Verify migration timestamps in electron/database/migrations/meta/_journal.json are monotonically increasing

Configuration​

  • Terms of Use acceptance flag is now required in settings (fail-closed default)
  • Cloud sync must be explicitly enabled in settings before sync operations
