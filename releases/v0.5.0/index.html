Release v0.5.0

Release Date: January 19, 2026

Summary​

CrewDeck v0.5.0 is a major feature release introducing enhanced project management, improved task workflows, advanced observability capabilities, and comprehensive quality-of-life improvements. This release focuses on productivity enhancements, better user experience through refined UI components, and robust error recovery mechanisms.

Features​

Terminal & Execution Enhancements​

  • Terminal Window Controls — Minimize, terminate, and maximize ongoing terminal operations for better multitasking
  • Interactive Terminal Sessions — Bidirectional interaction support in Claude terminal sessions
  • Terminal Status Indicators — Dynamic terminal indicator colors that match Kanban status for visual consistency
  • Terminal Session Naming — Changed terminal session naming from task title to task number for clarity

Command & Agent Workflows​

  • Command Discovery UI — New command discovery interface similar to agents discovery
  • Command Chaining — Configurable task execution pipeline with dynamic command sequencing
  • Execute Command Selection — Support for multiple agent assignment with auto-population from commands
  • Agent-Only Workflow — Execute tasks with agents without requiring command selection
  • Agent Discovery Update — Support for new agent reference format @"agent-name (agent)"
  • Verbose Mode — Changed Claude CLI flag from --print to --verbose for detailed output

Task Management​

  • Task View Modal — Comprehensive task detail modal for viewing complete task information
  • Task Editing — Enable editing of task title and command while in To Do status
  • Task Numbering System — Human-readable task identifiers (e.g., "ENG-0001") auto-generated from project names
  • Task Card Enhancements — Display worktree path, branch name, and orchestrated agents on task cards
  • PR URL Editing — Enable manual PR URL editing on completed tasks
  • Task Scoring — Ability to edit task scoring after completion
  • Task Deletion Confirmation — Confirmation dialog required before task deletion
  • File Attachments — Attach files to tasks with automatic storage and retrieval

Project & Navigation​

  • Collapsible Sidebar — Implement collapsible sidebar for project navigation
  • Department Onboarding Wizard — Step-by-step wizard for importing agents, commands, and skills to new repositories
  • Project Reordering — Move departments up and down in the sidebar
  • Department Visibility — Modify department visibility settings

Kanban Board Improvements​

  • Document Column — New Document column in Kanban board for documentation workflow
  • Done Column Sorting — Sort Done column by completion date (most recent first)
  • Auto-Sizing Layout — Kanban columns automatically stretch to fill available width
  • Task Review Workflow — Easy way to review tasks with improved review process

Config Management​

  • Skill Importing — Add skill importing functionality to onboarding setup
  • Config Generation — Add/remove/generate skills, agents, and commands from the UI
  • Template Management — Generate new configs and add from templates via Config tab
  • Detailed Config Views — Implement detailed view modals for agents, commands, and skills

Release & Repository Management​

  • Release Management System — Create and track releases with linked tasks and automated PR workflows
  • Release Wizard Improvements — Enhanced release creation workflow with better UX
  • New Repository Creation — Create new GitHub repositories directly from the app
  • Repository Link Display — GitHub repository link displayed on repos page

Observability & Analytics​

  • Agent Observability — Real-time tracing of agent decisions, tool usage, and execution timeline during task runs
  • Task Outcome Tracking — Record task completion status, duration, error counts, and user ratings for analytics
  • Analytics Dashboard — Visualize task metrics, activity feeds, department statistics, and performance trends

Error Recovery & Resilience​

  • Error Recovery System — Comprehensive error handling with React error boundaries, retry logic, and offline queue
  • Crash Recovery — Automatic crash recovery for terminal sessions with output preservation
  • Session Auto-Recovery — Terminal crash detection and buffer preservation

Documentation & User Experience​

  • User Guide — Comprehensive end-user documentation covering all features and workflows
  • Standalone HTML Docs — Technical and functional guides as standalone HTML files
  • CLAUDE.md and README.md Generation — Automated document generation for new repositories
  • Updated User Manual — User guide updated with Claude Config management features

Code Quality​

  • Test Coverage Campaign — Comprehensive testing to maintain 95% coverage threshold
  • Enhanced Productivity Features — Various productivity improvements across the application
  • README Updates — Updated README with latest features, documentation links, and architecture details

Bug Fixes​

  • Create Task Modal Display — Fixed issue where create task modal was not displaying correctly
  • Memory Leak Investigation — Addressed memory leak issues in terminal handling
  • Terminal Alignment — Fixed terminal text alignment issues for non-Claude subprocesses
  • Onboarding Stage Navigation — Fixed user navigation issues during onboarding stage
  • CI/CD Test Failures — Resolved unit test failures reported in CI/CD pipeline
  • Terminal Launch Issues — Fixed terminal not launching correctly in certain scenarios
  • Character Encoding — Fixed unreadable characters posted in terminal output
  • Agent Command Onboarding — Fixed issues when onboarding agents and commands
  • Claude CLI Exit Codes — Resolved "Claude CLI exited with code 1" errors
  • Agent Generation — Fixed issues when generating new agents
  • Terminal Text Alignment — Comprehensive terminal text alignment fixes
  • Department Navigation — Fixed navigation issues when moving between departments
  • Missing Task Board — Resolved task board not displaying in certain conditions
  • GitHub Command Formatting — Fixed formatting issues in GitHub command output
  • Task Modal Sizing — Fixed new task modal exceeding screen boundaries
  • Error Message Display — Improved error message presentation
  • Terminal Performance — Optimized terminal performance for long-running sessions
  • Document Stage Issues — Fixed Claude read issues in document stage
  • Performance Improvements — Multiple performance optimizations documented and implemented
  • Terminal Optimization — Advanced terminal performance optimizations
  • Unit Test Stability — Fixed flaky unit tests
  • Window Maximize Issues — Fixed layout issues when maximizing the window
  • PR Link Visibility — Display PR link on completed task cards
  • Build Completion Transition — Auto-transition task status on build completion
  • Run Button State — Hide Run button for tasks in To Do status
  • Project Name Display — Fixed department name repetition in UI
  • Terminal Session Overflow — Fixed terminal session overflow and scrolling issues
  • Deprecated Command Agents — Removed deprecated command agents from the system
  • Unnecessary UI Elements — Removed unnecessary UI buttons for cleaner interface
  • Task Rating — Fixed task rating/scoring functionality
  • Department Sorting — Fixed department up/down sorting functionality
  • Department Ordering — Fixed project ordering not persisting correctly

Breaking Changes​

None — This release maintains backward compatibility with v0.4.0.

Migration Notes​

For Users​

  • The Kanban board now includes a "Document" column between "In Review" and "Done"
  • Terminal sessions now display task numbers instead of task titles in tabs
  • Agent references now use the format @"agent-name (agent)" for clarity
  • Project sidebar is now collapsible — click the collapse button to toggle

For Developers​

  • New database tables: agentTraces, taskOutcomes
  • New services: TraceCaptureService, OutcomeTrackingService, CrashRecoveryService
  • Updated store pattern with offline queue support
  • Error boundary wrappers added to all page components

Technical Highlights​

Agent Observability Architecture​

The new observability system captures structured trace events during task execution:

  • Parses [TRACE:phase:type] description | metadata markers from terminal output
  • Stores traces in dedicated database with rich metadata
  • Provides filterable timeline UI for debugging and analysis

Error Recovery System​

Comprehensive error handling implemented across all layers:

  • React error boundaries with retry capability
  • Exponential backoff for network/IPC failures
  • Offline operation queue with persistence
  • Terminal crash detection and auto-recovery

Task Outcome Tracking​

Performance analytics for completed tasks:

  • Automatic outcome recording on task completion
  • PR merge detection via GitHub integration
  • User rating survey (1-5 stars) with optional comments
  • Analytics dashboard with trends and filtering
