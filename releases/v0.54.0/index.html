Release v0.54.0

Release Date: June 13, 2026

Summary​

Version 0.54.0 introduces a comprehensive ML-driven provider recommendation and project analytics system that intelligently recommends optimal AI providers and models for each workflow substage based on historical performance metrics, complexity scores, cost analysis, and level of effort. The release includes advanced data collection pipelines, analytics dashboards, and workload projection tools to help teams optimize AI agent deployment and forecast project capacity.

Major Features​

ML-Driven Provider Recommendation System​

  • Substage Execution Metrics Collection — Automatically captures and stores provider usage, model selection, execution cost, complexity score, and level of effort (LOE) for every agent substage
  • Provider/Model Recommendation Engine — ML model trained on historical data produces intelligent provider and model recommendations per substage with confidence scoring
  • Complexity & LOE Scoring Service — Analyzes substage execution characteristics to generate complexity and level-of-effort metrics that feed the recommendation engine
  • Provider Recommendation Panel — Interactive UI component for viewing and applying ML-driven provider recommendations with confidence indicators
  • Substage Execution Metrics Display — Dashboard view showing detailed execution metrics (cost, complexity, LOE, provider used, model) for each substage

Project Analytics & Workload Projection​

  • PR Statistics Extraction Pipeline — Automatically extracts and links GitHub PR statistics (lines added/removed, file changes, commit counts) to corresponding tasks for historical analysis
  • Historical Performance Analytics — Aggregates substage execution data to surface patterns, trends, and performance characteristics across projects
  • Workload Projection Service — Forecasts future project workload based on historical PR throughput and task complexity metrics
  • WorkloadProjectionView Component — Visualizes PR statistics (per-task and cross-project), velocity trends, and projected workload estimates with time-series analysis
  • Cost Dashboard Integration — Enhanced cost tracking and analysis with historical performance data and ML-driven recommendations

Data & Analytics Infrastructure​

  • Analytics Domain Types & IPC Channels — Full type contracts for analytics operations with Zod validation schemas
  • Provider Analytics Zustand Store — Centralized state management for recommendation data, historical metrics, and workload projections
  • Substage Analytics Database Schema — New tables for substage execution metrics, PR task statistics, and recommendation tracking
  • Historical Substage Analytics Aggregator — Service for querying and aggregating historical substage performance data
  • Project Recommended Provider Service — Service for managing provider recommendations at project scope

Testing & Quality Assurance​

  • Quality Review Audit — Comprehensive security and architecture compliance audit of the entire ML recommendation subsystem including IPC security, Zustand patterns, Drizzle schema consistency, and test coverage verification
  • Provider Analytics Store Tests — Full test coverage for recommendation and analytics state management
  • Test Coverage for Metrics Recording — Unit tests for substage metrics collection and cost tracking
  • Evidence Collection Improvements — Enhanced PR statistics collection to ensure data completeness

Bug Fixes​

Critical Fixes​

  • Fix OpenAI/Anthropic Provider Model Handling — Corrected provider model selection and tracking in task execution pipeline
  • Implement LLM-Powered Troubleshooting — Enhanced error analysis and debugging capabilities for agent execution failures
  • Evidence Collection in PR Analysis — Fixed missing field collection in PR statistics extraction pipeline
  • WorkloadProjectionView Test Failures — Resolved empty-state rendering bugs in workload projection display
  • Real SQLite Provider-Mismatch Cases — Added proper test isolation for provider configuration mismatch scenarios

UI & UX Fixes​

  • Icon Size Standardization — Standardized icon sizes across UI components for visual consistency
  • Dashboard Metrics Display — Fixed rendering of complexity scores and execution metrics in analytics dashboards

Technical Improvements​

Architecture & Design​

  • Introduced analytics domain with dedicated IPC channels and Zustand store pattern for recommendation data
  • Enhanced cost tracking with substage-level granularity and complexity-based analysis
  • Implemented findSafeFlushEnd() pattern for UTF-8 and ANSI-safe terminal output handling

Database & Schema​

  • Added substage_execution_metrics table for collecting provider, model, cost, complexity, and LOE data
  • Added pr_task_stats table for linking GitHub PR statistics to task entities
  • Added project_recommended_provider table for storing ML-driven provider recommendations
  • Added substage model override tables for manual provider/model selection

Performance & Reliability​

  • Optimized analytics queries with proper indexing for historical data aggregation
  • Improved resource management for terminal output buffering with safe UTF-8/ANSI splitting
  • Enhanced data integrity with concurrent insert handling using UNIQUE constraints

Breaking Changes​

None. All changes are backward compatible.
