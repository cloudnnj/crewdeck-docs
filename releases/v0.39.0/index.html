Release v0.39.0

Release Date: May 15, 2026

Summary​

CrewDeck v0.39.0 introduces a major redesign of the task management UI with semi-fullscreen panels, a new context continuity engine for workflow state preservation, enhanced AI workflow management with typed agent messages and semantic task decomposition, and a VSCode launcher integration for seamless development environment access.

Features​

Task Panel Redesign​

  • Semi-fullscreen in-place panels replacing centered modals for improved UX
  • Two-column layout with primary form on the left and dynamic right rail aggregating recommendations, cost metrics, compliance scans, and agent memory
  • Consistent styling following ProjectEditPanel pattern with proper scrolling behavior (overflow-hidden parent + flex-shrink-0 header/footer + flex-1 min-h-0 overflow-y-auto body)

Context Continuity Engine​

  • Automatic stage handoff memos synthesized between Kanban column transitions using LLMService
  • Historical context injection into next execution session via GuidanceBridgeService
  • Persistent workflow metadata stored in workflow_runs and workflow_steps tables for full execution traceability

Typed Agent Message Schema​

  • AgentMessage value object replacing prose-based handoff artifacts with structured, machine-readable messages
  • Programmatic agent handoff inspection enabling better integration with workflow systems
  • Backward-compatible adapter for legacy RelayHandoff format during migration

WorkflowRunService​

  • Engine-owned lifecycle management with start, resume, cancel, and subscribe operations
  • Durability via idempotent step creation using (runId, idempotencyKey) UNIQUE constraint and re-fetch pattern
  • Event-driven workflow updates emitted through EventBus for reactive UI synchronization

Semantic Task Decomposition​

  • Agent-match scoring integrated into TaskDecompositionService for intelligent subtask recommendations
  • Workflow persistence storing decomposition as workflow_runs (mode='decomposition') with individual steps
  • Atomic idempotency using the same (runId, idempotencyKey) constraint pattern for safe concurrent creation

VSCode Launcher Button​

  • Native IDE integration with new third worktree shortcut alongside terminal and CLI Agent buttons
  • Task-isolated PTY spawning launching VSCode in task worktree with code . bootstrap command
  • Consistent UI treatment mirroring CLI Agent button scaffolding with VSCode-blue accent color

Bug Fixes​

Cost Cache Metrics Display​

  • Fixed zero-token display issue in TaskCostMetricsWidget caused by incorrect row selection
  • Root cause: ordering by timestamp with ties + stale reads against write-behind buffer
  • Solution: order by createdAt DESC, fetch top 20 candidates, filter for non-zero tokens

Breaking Changes​

None
