Release v0.46.0

Release Date: May 27, 2026

Summary​

This release focuses on improving the Prompt Explorer and provider management system. Key improvements include fixing UI layout issues, ensuring cost estimates display correctly, adding model capability detection for temperature parameters, persisting CLI execution mode preferences, and wiring provider assignments across all prompt execution paths.

Features​

  • Persist CLI Execution Mode Selection Across Restarts — The CLI execution mode preference is now saved to the database and automatically restored after application restarts. Users will no longer experience fallback to SDK mode unexpectedly.

  • Wire Provider Assignment to All Prompt Execution Paths — Expanded provider assignment support to all 22 remaining prompt execution paths, enabling users to configure custom LLM providers for every prompt type. Previously only six prompts honored user-assigned providers; now all prompts route through the unified assignment resolver.

  • Fix Temperature Parameter Error for Anthropic Opus in Prompt Explorer — Added model capability detection to prevent 400 invalid_request_error responses when using temperature parameters with models that don't support them (Anthropic Opus 4.x and OpenAI reasoning-tier models o1, o3, o4). Temperature is now silently omitted for restricted models while remaining functional for all others.

Bug Fixes​

  • Fix Missing Cost Estimates in Prompt Explorer for Anthropic Sonnet — The Prompt Test Runner now displays cost estimates immediately when opened. Previously, cost estimates only appeared after visiting the Pricing settings panel or waiting for an upstream refresh. Added a post-run "Cost" cell in the Last Result grid showing token-based cost calculations when available.

  • Fix Prompt Edit Field Overflow in Prompt Explorer — Fixed a UI layout bug where long single-line content in the prompt edit textarea forced horizontal scrolling. The textarea now wraps text while preserving newlines and whitespace formatting from the underlying markdown prompt body.

Technical Changes​

Backend Services​

  • New ModelCapabilities service provides runtime detection of models with restricted parameter support using regex pattern matching
  • New PromptLLMDispatcher unified interface for resolving prompt assignments across all execution paths
  • Configuration management for persisting backend execution mode preference (SDK vs CLI)

Frontend Components​

  • Updated PromptTestRunner component with pricing hydration on mount and post-run cost cell
  • Updated PromptEdit component textarea wrapping behavior
  • Removed deferred-notice from PromptConfigureProviderModal (provider assignments now take effect immediately)

Database​

  • No migrations required; all changes are backwards compatible

API / IPC​

  • No new IPC channels or contract changes

Breaking Changes​

None — all changes are fully backwards compatible.

Known Limitations​

  • OpenAI model pricing (e.g., gpt-4o) remains absent from the bundled pricing snapshot; reconciliation with upstream LiteLLM data is a follow-up task
  • claude-opus-4-7 is in the model picker but absent from the pricing snapshot, showing '—' for cost estimates
  • Backend token usage capture is still returning null; post-run cost estimates display '—' until this upstream work completes
