Release v0.14.0

Release Date: February 28, 2026

Summary​

Version 0.14.0 delivers a comprehensive framework modernization, a full telemetry pipeline, and continued security and terminal hardening. On the framework side, this release upgrades Electron 38 to 40 (with electron-vite 3 to 5), migrates react-router-dom 6 to 7 across 17+ files, upgrades @xterm/xterm 5 to 6, @dnd-kit/sortable 8 to 10, @octokit/rest 20 to 22, ESLint 9 to 10, and @testing-library/react 14 to 16. Security hardening continues with dual blocklist/allowlist executable control, parameterized spawn replacing shell string concatenation, Chromium renderer sandbox restoration via CJS preload conversion, IPC sender frame validation, removal of raw GitHub token exposure from the renderer, Electron safeStorage credential fallback, production CSP hardening, and sandbox security policy configuration. A new opt-in telemetry pipeline forwards anonymized usage data to a remote API with SHA-256 hashed user IDs, batched delivery with exponential backoff, sampling rate configuration, and a transparent first-run opt-in prompt. Terminal improvements include save-to-file output export, cursor-up-aware ring buffer storage fixing progress indicator stacking, improved padding, and interactive terminal launch reliability fixes. Task management gains per-project Kanban stage selection, configurable execution phases, two-column modal layouts for create and view/edit, shared WCAG-compliant Modal and ToggleSwitch components, and conditional epic filter visibility. The LLM stack is consolidated onto fully local Ollama with qwen3:8b and nomic-embed-text, removing the external OpenRouter dependency entirely.

Features​

Security & Hardening​

  • Dual Blocklist/Allowlist Executable Control (PR #807) -- Replaces the mutually exclusive executable mode with two independent, simultaneously active lists where allowlist overrides blocklist, giving users fine-grained control over terminal command execution within the sandbox
  • Parameterized Spawn (PR #822) -- Replaces shell string concatenation with parameterized spawn() calls, eliminating command injection vectors in subprocess creation
  • Chromium Renderer Sandbox Restoration (PR #823) -- Converts preload script to CommonJS format, restoring Chromium's renderer process sandbox for stronger process isolation
  • IPC Allowlist Validation & Sender Frame Checks (PR #824) -- Adds allowlist validation to settings IPC channels and verifies sender frame origin on all IPC calls to prevent unauthorized access
  • Remove Raw GitHub Token from Renderer (PR #825) -- Removes the IPC channel that exposed raw GitHub personal access tokens to the renderer process, reducing credential exposure surface
  • Electron safeStorage Credential Fallback (PR #827) -- Replaces file-based credential fallback with Electron's safeStorage API, ensuring credentials are encrypted at rest even when keytar is unavailable
  • Production CSP & Terminal Sandbox Default (PR #852) -- Hardens Content Security Policy for production builds and enables terminal sandbox by default for new installations
  • Sandbox Security Policy Configuration (PR #856) -- Adds settings.local.json-based sandbox security policy configuration allowing users to customize sandbox behavior per environment
  • GitHub API in Sandboxed Environments (PR #882) -- Enables GitHub API access within sandboxed terminal sessions by routing requests through the main process
  • Sandbox Settings Gitignore (PR #896) -- Automatically adds Claude sandbox settings to .gitignore when sandboxing is enabled, preventing credential leakage into version control

Terminal Improvements​

  • Terminal Screen Updates (PR #826) -- Fixes terminal screen corruption during large data bursts with improved output buffering and rendering pipeline
  • Save Terminal Output to File (PR #839) -- Users can export terminal session output as clean .log files stripped of ANSI escape codes, available from both the ViewTaskModal header and TerminalPanel tab bar
  • Decomposed TaskExecutionService (PR #844) -- Extracts spawnTrackedPty helper from monolithic TaskExecutionService, improving testability and separation of concerns
  • Terminal Edge Padding (PR #909) -- Increases xterm.js terminal padding from 8px to 12px on all edges, improving readability with more breathing room between text and container boundaries

Telemetry & Analytics​

  • Telemetry API Forwarding Pipeline (PR #858) -- Opt-in pipeline forwarding locally-collected usage telemetry to a remote API with SHA-256 anonymized user IDs, batched delivery (max 2000 events), exponential backoff retry, and rate-limit handling
  • Remote Telemetry Settings UI (PR #860) -- Settings page UI for configuring remote telemetry forwarding, including API endpoint, enable/disable toggle, and connection testing
  • safeRecord() Utility & Typed Metadata (PR #862) -- Type-safe safeRecord() utility for telemetry recording with double-fault protection and TelemetryEventMap providing compile-time metadata checking
  • Task Lifecycle Telemetry (PR #875) -- Wires task_created, task_status_changed, and task_completed telemetry events with typed metadata including duration, agent count, and outcome
  • Project & Repo Telemetry (PR #876) -- Wires project_created and repo_connected telemetry events with project configuration metadata
  • App Startup Telemetry (PR #879) -- Wires app_startup telemetry event in the Electron main process capturing startup duration, platform, and version
  • Terminal Session Telemetry (PR #881) -- Wires terminal session lifecycle telemetry events (session_started, session_completed) with duration, output size, and session type metadata
  • Sampling Rate Configuration (PR #884) -- Adds configurable samplingRate to TelemetryApiClient allowing percentage-based event sampling to control telemetry volume
  • First-Run Telemetry Opt-In Prompt (PR #885) -- One-time modal dialog on first launch transparently explaining telemetry data collection with equal-prominence "Enable Analytics" and "No Thanks" buttons
  • Comprehensive Telemetry Tests (PR #889) -- Full test coverage for all Wave 1 telemetry instrumentation across task, project, terminal, and app lifecycle events

Task & Project Management​

  • Team Agent Environment Injection (PR #821) -- Extends sandbox settings to inject CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS environment variable into .claude/settings.local.json, ensuring sub-processes spawned by the lead agent inherit the team feature flag
  • Allowed Tools Configuration (PR #834) -- Adds UI for configuring additional allowable tools in the sandbox, extending the executable control system to tool-level permissions
  • Task Execution Phase Customization (PR #835) -- Removes hardcoded command references (refine-prompt, review-pr, improve-pr) from the execution pipeline, making prompt refinement, code review, and code improvement phases configurable and individually disableable per-project
  • Per-Project Kanban Stage Selection (PR #845) -- Users can toggle optional Kanban stages (in_progress, in_review, document) on or off per project; tasks in disabled stages display in the nearest preceding enabled stage
  • Shared Modal & ToggleSwitch Components (PR #851) -- WCAG-compliant shared <Modal> and <ToggleSwitch> components replacing 9 duplicated modal implementations and 6 inline toggle implementations with consistent ARIA attributes and keyboard support
  • Store Helpers & Phase Factory Adoption (PR #863) -- Migrates 16 Zustand stores to shared Map-based utility functions and introduces createPhaseActions factory eliminating triplicated phase management logic
  • Epic Conditional Visibility (PR #865) -- Epic filter pills on the Kanban board only appear when the epic has at least one currently visible task, automatically resetting stale filters and preventing UI clutter from past development cycles
  • Feature Discovery Hook (PR #880) -- useFeatureDiscovery() React hook with Zustand-backed deduplication for tracking first-time feature interactions, integrated alongside store helpers adoption and typed telemetry metadata
  • Feature Discovery Integration (PR #883) -- Integrates the feature discovery hook into key feature entry points (task creation, terminal launch, debate execution) for usage tracking
  • Create Task Modal Two-Column Layout (PR #901) -- Redesigns the Create Task Modal from a narrow single-column layout to a wider two-column grid layout (max-w-4xl), reducing vertical scrolling by placing related fields side-by-side
  • View/Edit Task Modal Two-Column Layout (PR #905) -- Aligns the ViewTaskModal with the CreateTaskModal two-column grid layout for visual consistency across all task modal experiences, with timestamps separated below the grid

AI & LLM​

  • Local Ollama Stack Consolidation (PR #830) -- Switches the default chat model to qwen3:8b and replaces external OpenRouter API for task embeddings with local Ollama nomic-embed-text (768-dim), removing all external API key management and enabling fully offline operation

Framework & Dependency Upgrades​

  • GitHub Actions Upgrades (PR #805, #890) -- Upgrades all GitHub Actions to latest major versions across CI/CD workflows
  • @testing-library/react ^14 to ^16 (PR #894) -- Major version upgrade of React testing library with updated test patterns
  • ESLint ^9 to ^10 (PR #895) -- Upgrades ESLint and @eslint/js to version 10 with updated rule configurations
  • Electron ^38 to ^40 & electron-vite ^3 to ^5 (PR #899) -- Atomic major version upgrade of Electron and electron-vite with native module ABI compatibility verification
  • @octokit/rest ^20 to ^22 (PR #902) -- Upgrades Octokit REST client with auth flow verification ensuring GitHub API integration remains functional
  • @dnd-kit/sortable ^8 to ^10 (PR #903) -- Upgrades drag-and-drop ecosystem including core and utilities packages
  • @xterm/xterm ^5 to ^6 (PR #904) -- Upgrades xterm.js terminal emulator and all addon packages to the latest major version
  • react-router-dom ^6 to ^7 (PR #906) -- Migrates React Router across 17+ files to version 7 with updated API patterns
  • Hono 4.12.1 to 4.12.3 (PR #922) -- Patch upgrade for the Hono web framework in the MCP server

CI/CD & DevOps​

  • Pin CI Node Version to 22 (PR #843) -- Pins the CI Node.js version to 22 to resolve npm ci failures caused by version drift
  • Replace gh CLI with curl + GH_TOKEN (PR #888) -- Replaces GitHub CLI usage with direct curl + GH_TOKEN in all command files for more portable CI scripts
  • Native Module ABI Compatibility Verification (PR #892) -- Spike verifying that native modules (better-sqlite3, node-pty, keytar) are ABI-compatible with Electron 40
  • Batch PR Merge Script (PR #915) -- Adds a batch PR merge script with validation and Claude integration for streamlined release merges
  • Skip Tests on Non-Code Changes (PR #917) -- Skips the full test suite when no code-relevant files change, reducing CI time for documentation-only PRs

IPC & Infrastructure​

  • IPC Origin Dev Mode (PR #828) -- Adjusts IPC origin validation for development mode to support hot-reload and dev server workflows

Bug Fixes​

  • Fixed blocked and allowed executables not working (PR #811) -- Enforced sandbox executable lists in Claude CLI by integrating dual-list validation into the command execution pipeline
  • Fixed multi-word entries removed from allowed executable list (PR #812) -- Allowed executable list now correctly preserves multi-word command entries (e.g., "git commit") instead of splitting them
  • Fixed terminal freeze on team work execution (PR #817) -- Resolved terminal freeze when selecting team work execution mode by fixing race condition in PTY environment injection
  • Fixed terminal session readability (PR #818) -- Fixed character bleeding and rendering artifacts in terminal sessions caused by incorrect column width calculations
  • Fixed terminal scroll jumping to mid-point (PR #819) -- Terminal scroll position no longer jumps to the middle of output after user input; viewport remains anchored correctly
  • Fixed terminal screen rendering (PR #836) -- Resolved additional terminal screen edge cases with large data bursts and rapid output
  • Fixed project setup step configuration errors (PR #838) -- Project setup wizard no longer throws configuration errors during step transitions
  • Fixed terminal session launch from task card (PR #840) -- Users can now successfully launch into a terminal session from the task card shortcut icon
  • Fixed save log button not generating output (PR #841) -- Save log button now correctly generates and saves terminal output to file
  • Fixed interactive terminal input and focus (PR #846) -- Resolved interactive terminal input failures and focus timing issues caused by stale isRunning state
  • Fixed terminal tab scroll reset on tab switch (PR #847) -- Terminal scroll position preserved correctly when switching between tabs, fixing residual scroll reset bug
  • Fixed epic assignment to tasks (PR #849) -- Epic dropdown selection now correctly persists when assigning an epic to a task
  • Fixed CLAUDE.md generation errors (PR #850) -- CLAUDE.md generation no longer fails with array validation errors when processing project configuration
  • Fixed sequential run terminal rendering (PR #853) -- Sequential task execution no longer causes terminal rendering overlap between consecutive runs
  • Fixed interactive terminal launch failure (PR #857) -- Resolved intermittent interactive terminal launch failures by fixing initialization timing and adding SonarCloud code quality improvements
  • Fixed false positive command rejections (PR #859) -- Sandbox command validator no longer falsely rejects commands when task content coincidentally matches blocked executable patterns
  • Fixed epic association for generated tasks (PR #864) -- Tasks generated from AI task generation now correctly inherit the parent epic association
  • Fixed settings.local.json configuration (PR #867) -- Corrected malformed sandbox configuration in settings.local.json that caused parsing failures
  • Fixed telemetry noise for issue sync (PR #868) -- issue_sync_checked telemetry event now only emits when actual changes are found, reducing telemetry noise
  • Fixed file attachments not accessible to agents (PR #891) -- Task file attachments are now accessible to Claude agents during execution by instructing the agent to use the Read tool for gitignored attachment paths
  • Fixed epic display in compact Kanban (PR #893) -- Epic filter pills now only display when the full Kanban board view is active, not in compact mode
  • Fixed keychain password prompts after Electron upgrade (PR #897) -- Resolved approximately 10 repeated macOS Keychain password prompts during logout/re-auth flows caused by Electron 38 to 40 migration invalidating stored keychain entries
  • Fixed project integration branch for PR creation (PR #898) -- PR creation now targets the correct integration branch configured for the project instead of defaulting to main
  • Fixed debate context folder committed to git (PR #900) -- .crewdeck-context/ folder is now automatically added to .gitignore before debate execution, preventing temporary context files from polluting the repository's git history
  • Fixed terminal progress indicator stacking (PR #907) -- CLI progress indicators (e.g., Claude Code's "Slithering...") now render as a single updating line instead of stacking multiple lines, fixed at both the ring buffer storage layer (cursor-up-aware overwrites) and replay layer (defense-in-depth ANSI stripping)
  • Fixed CMD+C closing task edit modal (PR #908) -- Pressing CMD (Meta key) on macOS no longer closes the task edit modal; replaced simple onClick backdrop close with mousedown+click tracking pattern that filters out synthetic pointer events from modifier keys
  • Fixed interactive terminal blank after launch (PR #910) -- Resolved blank terminal after tab opens by adding missing ungate() calls in safeFit() early-return paths within TerminalInstanceManager.attachNew()
  • Fixed HashRouter for Electron file:// protocol (PR #916) -- Restored HashRouter for Electron's file:// protocol compatibility after the react-router-dom v7 migration which defaulted to BrowserRouter
  • Fixed batch-merge-prs silent exit (PR #918) -- Resolved silent exit in batch-merge-prs.sh caused by GraphQL node limit exceeding API response capacity
  • Fixed batch-merge-prs validation logic (PR #919) -- Improved batch PR merge validation logic and fixed unbound variable errors in edge cases
  • Fixed CI check name mismatch (PR #921) -- Updated CI check name to match the workflow name expected by branch protection rules
