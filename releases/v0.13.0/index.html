Release v0.13.0

Release Date: February 23, 2026

Summary​

Version 0.13.0 is a security-focused release delivering comprehensive hardening across every layer of the application. This release introduces BrowserWindow sandbox mode with main-process IPC migration, Zod-based input validation on all IPC channels, prompt injection detection with an LLM input firewall, PBKDF2 key derivation for secure storage, Content Security Policy hardening, command risk classification, and automated dependency vulnerability scanning in CI. Terminal performance receives further optimization through decoupled xterm.js lifecycle management, lazy-loaded addons with tiered loading, RAF-based write batching with priority scheduling, backpressure flow control between PTY and renderer, a return-to-pool PTY lifecycle, and CircularBuffer for memory-efficient output storage. New user-facing features include an Epic concept for grouping tasks, VCS-driven task templates, a command approval workflow UI, terminal keyboard shortcuts, push notification deep-linking to terminal sessions, and a security dashboard UI. SonarCloud integration is fully established with ESLint configuration, project properties, and consolidated audit reports.

Features​

Security & Hardening​

  • Terminal Session Sandboxing (PR #651) — Resource limits and sandboxed execution environment for terminal sessions preventing runaway processes
  • BrowserWindow Sandbox Mode (PR #702, #762) — Enable Chromium sandbox for renderer process and migrate socket connection to main process IPC for secure communication
  • Zod-Based IPC Validation (PR #656) — Runtime input validation middleware on all IPC channels using Zod schemas, rejecting malformed payloads before handler execution
  • Centralized IPC Input Validation (PR #758) — Unified validation layer with Zod schemas applied consistently across all IPC handler modules
  • Path/URL Validation (PR #667) — Validate file paths and URLs in shell IPC handlers and setWindowOpenHandler to prevent path traversal and open redirect attacks
  • Hardened Agent Discovery (PR #668) — Agent discovery pipeline protected against shell injection and path traversal via input sanitization and allowlisted characters
  • PBKDF2 Key Derivation (PR #666) — Replace raw keytar storage with PBKDF2-derived encryption keys for secure credential storage
  • Content Security Policy Hardening (PR #693) — Stricter CSP directives and credential cache TTL to limit exposure window of cached tokens
  • Secure GitHub Token Passing (PR #695) — GitHub personal access tokens passed via environment variables instead of command-line arguments in git CLI operations
  • Prompt Injection Detection (PR #757) — Pattern detection and LLM input firewall scanning user inputs for injection attempts before forwarding to AI models
  • Command Risk Classification (PR #696) — Scoring engine classifying commands by risk level (safe, moderate, dangerous) to inform permission decisions
  • Harden Skip-Permissions Policy (PR #777) — Strengthened skip-permissions policy with LLM context sanitization preventing prompt leakage through tool outputs
  • Secure Ollama Connection (PR #751) — Ollama LLM connections hardened against DNS rebinding and MITM attacks with origin validation and TLS verification
  • Credential Access Control (PR #649) — Access control layer governing which services can read/write stored credentials
  • Fix Command Injection (PR #665) — Replace all exec() calls with execFile() in permission hook service to prevent shell command injection
  • Security Posture Documentation (PR #752) — Comprehensive security posture document for senior leadership covering threat model, controls, and compliance
  • Claude Code Permissions Review (PR #711, #715) — Security review of Claude Code permission configurations ensuring least-privilege defaults

Terminal Performance & UX​

  • Decoupled xterm.js Lifecycle (PR #657) — xterm.js terminal instances managed independently from React component lifecycle, preventing unnecessary re-initialization on re-renders
  • Direct xterm.js Theme Switching (PR #686) — Theme changes applied directly to xterm.js options bypassing React re-renders for instant visual updates
  • Lazy-Loaded xterm.js Addons (PR #692) — Three-tier addon loading strategy (critical on mount, deferred on idle, optional on demand) reducing initial terminal startup time
  • RAF-Based Write Batching (PR #688) — RequestAnimationFrame-based output batching with priority scheduling ensuring smooth rendering under high output volume
  • Terminal Session Multiplexer (PR #689) — Binary IPC framing protocol for multiplexing multiple terminal sessions over a single communication channel
  • CircularBuffer (PR #647) — Fixed-size circular buffer replacing unbounded string concatenation for terminal output storage, preventing memory growth over long sessions
  • Graceful Shutdown Orchestration (PR #690) — Coordinated shutdown sequence with PTY health checks ensuring all terminal processes terminate cleanly before app exit
  • Scroll to Top (PR #718) — Users can scroll to the top of full terminal session history to review earlier output
  • Terminal Keyboard Shortcuts (PR #760) — Keyboard shortcut manager with scope context for terminal operations (copy, paste, clear, scroll, search)
  • Pause/Terminate Confirmation (PR #742) — Confirmation dialogs before pausing or terminating terminal sessions to prevent accidental data loss
  • Backpressure Flow Control (PR #748) — Flow control between PTY output and renderer consumption preventing buffer overflow when output exceeds rendering speed
  • PTY Process Pool Return-to-Pool (PR #733) — PTY processes returned to pool after session close instead of being destroyed, reducing spawn latency for subsequent sessions

Task & Project Management​

  • Epic Concept (PR #747) — Group tasks by parent theme or source document with epic-level status tracking and progress aggregation
  • VCS-Driven Task Templates (PR #786) — Task templates stored in git repositories enabling version-controlled template sharing across team members
  • Command Approval Workflow (PR #719) — User-controlled UI for reviewing and approving commands before execution, replacing automatic execution for sensitive operations
  • Push Notification Navigation (PR #727) — Clicking a push notification navigates directly to the related terminal session for immediate context
  • Remove Command from AI Tasks (PR #735) — AI-generated tasks no longer auto-assign commands; orchestrator agent is set as first agent for better human oversight
  • Project Setup Branch Strategy (PR #646) — Branch strategy configuration integrated into project setup flow with trunk-based, GitFlow, and custom options
  • Repo Setup Always Creates PRs (PR #663) — New repository setup workflow always creates PRs for configuration changes instead of committing directly

AI & Intelligence​

  • Question Detection Notifications (PR #658) — Detect when Claude Code asks questions during execution and surface desktop notifications so users can respond promptly
  • Capability-Based Agent Permissions (PR #732) — Agent permission model where agents declare required capabilities and users grant consent before execution
  • Replace Voyage AI with OpenRouter (PR #728) — Embedding API switched from Voyage AI to OpenRouter for broader model access and simplified API key management
  • Terminal Shortcut Cleanup (PR #782) — Removed terminal shortcut visual indicators that were adding UI noise without usability benefit

Code Quality & DevOps​

  • SonarCloud Integration (PR #738, #741, #744, #739, #749, #753) — Full SonarCloud setup with sonar-project.properties, ESLint config for SonarCloud rules, and consolidated audit reports across Electron main process, React frontend, and shared types
  • ESLint SonarCloud Config (PR #749) — ESLint configuration aligned with SonarCloud quality profiles for consistent static analysis
  • Automated Dependency Scanning (PR #788) — CI pipeline stage for automated dependency vulnerability scanning with blocking on critical/high findings
  • SonarQube IDE Integration (PR #784) — SonarLint extension configuration for real-time IDE feedback matching SonarCloud quality gates
  • Fix Tests Command (PR #703) — New /fix-tests slash command for automated test failure investigation and resolution
  • Refactoring Audit (PR #761) — Comprehensive audit identifying refactoring opportunities across the codebase

  • Updated PR Commands (PR #731) — /review-pr and /improve-pr commands updated to reference SonarCloud quality standards

Documentation & Infrastructure​
