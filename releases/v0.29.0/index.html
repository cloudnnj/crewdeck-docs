Release v0.29.0

Release Date: April 9, 2026

Summary​

v0.29.0 introduces major enhancements to project onboarding, adds comprehensive token usage analytics, expands marketplace capabilities with hook distribution support, and includes critical bug fixes for task execution determinism and terminal session handling.

Features​

Human-Like Project Onboarding Flow​

  • Replaced traditional template picker with conversational AI-guided project setup
  • Conducts multi-turn interview to understand project requirements and recommend marketplace resources
  • Leverages Claude Messages API for intelligent onboarding when Anthropic Platform API key is configured
  • Falls back to existing OnboardingWizard for users without API key setup
  • Automatically generates missing project resources based on interview responses

Claude Token Usage Dashboard​

  • New dedicated dashboard for parsing and analyzing token consumption from local JSONL session files
  • Displays comprehensive metrics: total tokens, input/output token breakdown, cache hit rates, session counts
  • Supports flexible date range filtering (7d, 30d, 90d, All time)
  • Interactive charts and visualizations using inline SVG (no external charting library dependency)
  • Project and model distribution breakdowns for detailed analytics
  • Distinct from existing Claude Usage admin API monitoring

Marketplace Hook Distribution​

  • Extended marketplace installation to support hook script files (.sh) alongside configuration
  • Hook packages now distribute both manifest JSON and shell scripts
  • Seamless installation of hooks to target repo's .claude/hooks/ directory
  • Hook preview UI shows which event types and scripts will be installed
  • Proper git staging and unstaging of both settings.json and hook files

Chat Panel Enhancements​

  • Added chat with agent action for improved agent interaction
  • Enhanced agent list with chat button functionality
  • Improved user experience for direct agent communication

Security Improvements​

  • Added security review flow for agent onboarding
  • Enhanced credential handling and API key validation
  • Improved isolation and permission controls

Additional Enhancements​

  • Auto-rate completed tasks via sentiment analysis
  • Disable refinement flag for task execution customization
  • Automatic retry mechanism for resilience in agent operations
  • Inject terminal output context into agent analysis
  • Improved marketplace distribution workflow

Bug Fixes​

Task Execution Determinism​

  • Fixed skipped deterministic steps (git commit + push) after stop hook implementation
  • Sentinel detection now correctly reports completion despite non-zero exit codes
  • Phase 11 now executes correctly in both execute() and executeCommandChain() flows

Terminal Session Handling​

  • Fixed terminal transcript download for complete session output capture
  • Improved terminal session data integrity and completeness

Foreign Key Constraints​

  • Resolved foreign key constraint failures in PrWatchAuditService flush operations
  • Enhanced data consistency in watch audit operations

Logging and Loop Prevention​

  • Fixed infinite loop logging for improved system stability
  • Reduced unnecessary logging overhead

Quality Improvements​

  • Resolved Codacy reported code quality issues
  • Fixed React error handling in PR watch components
  • Fixed autonomy building count display issues
  • Improved error messaging and handling throughout

Breaking Changes​

None
