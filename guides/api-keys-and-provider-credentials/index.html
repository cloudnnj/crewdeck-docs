API Keys and Provider Credentials

CrewDeck works with several AI and developer services. Some features need a key or a sign-in from one of them, and many features need nothing at all. This guide lists which credential each feature needs, where you enter it in the app, and where to get it.

Before you start​

Open Settings. The tabs that matter for credentials are:

  • Integrations: LLM Provider, OpenAI TTS Model, Voice Dictation, GitHub Integration, Jira, and Code Quality.
  • AI & Tools: Claude Authentication, Codex Authentication, Custom Secrets and MCP server settings.
  • CloudSync: cloud sync sign-in.

Credential panels show a "configured" message once a key is saved, and a Remove API Key button you can use to delete it.

Agent runs​

Codex (OpenAI) backend​

Codex runs can authenticate in one of two ways. Pick the method under AI & Tools → Codex Authentication.

  • Device Code (ChatGPT sign-in). Click Sign in with Device Code. CrewDeck starts the codex command-line tool, which shows a short code and a verification link. Enter the code in your browser to finish. This path requires the Codex CLI to be installed and on your command path. CrewDeck does not store the ChatGPT tokens itself.
  • OpenAI API Key. Select OpenAI API Key and save an OpenAI key under Integrations → LLM Provider → OpenAI Platform API Key. Get the key from platform.openai.com.

If you are signed in with Device Code and also have an API key saved, Codex runs use the Device Code sign-in. The API key is used only when no device sign-in is active.

Clicking Clear Login under Device Code removes the device sign-in.

Claude Code backend​

Pick the method under AI & Tools → Claude Authentication. There are three options.

  • OAuth Token. Uses a Claude OAuth token. You can keep several Claude accounts and choose which one a run uses.
  • API Key. Uses an Anthropic API key. Save it under Integrations → LLM Provider → Anthropic Platform API Key. Get the key from console.anthropic.com.
  • CLI Fallback. CrewDeck adds no credential of its own. Claude Code uses whatever login is already on your machine. This is the default when no method has been chosen. You must have Claude Code installed and signed in outside CrewDeck.

LLM provider (for prompt and assistant features)​

Under Integrations → LLM Provider you choose an Active provider from the drop-down. Features that route to a default LLM use this provider. Each provider has its own key panel, and keys stay saved even when that provider is not active.

  • Anthropic (Claude). Key from console.anthropic.com. Panel: Anthropic Platform API Key.
  • OpenAI. Key from platform.openai.com. Panel: OpenAI Platform API Key.
  • Google Gemini. Key from aistudio.google.com. Panel: Google Gemini API Key.
  • xAI (Grok). Shown as "coming soon". Its option cannot be made active yet, so you do not need a key for it.

Each provider panel has a Test Connection button, which is enabled once a key is saved.

If the active provider has no key saved, features that can fall back do so to Claude Code instead of failing. Save a key for the provider you want to use so that this fallback does not apply.

Podcasts​

Podcast generation has two parts: the script and the audio. The audio always uses OpenAI.

  • Script. The script is written by your active LLM provider. If that provider has no key saved, CrewDeck falls back to Claude Code.
  • Audio. Requires an OpenAI API key, saved under Integrations → LLM Provider → OpenAI Platform API Key. Without it, audio generation cannot run.

Settings you can change:

  • Integrations → OpenAI TTS Model sets the text-to-speech model. The panel lists the supported models and shows the default.
  • Integrations → Release Podcasts Output Folder sets where release podcast audio is saved.
  • Integrations → News Podcasts Output Folder sets where news podcast audio is saved.

Voice dictation​

Voice dictation transcribes your speech with OpenAI. It requires an OpenAI API key, saved under Integrations → LLM Provider → OpenAI Platform API Key. Set up the feature and the push-to-talk shortcut under Integrations → Voice Dictation.

GitHub​

GitHub access is needed to clone repositories, work with pull requests and discover agents in GitHub repositories. Set it up under Integrations → GitHub Integration. There are two ways to connect.

  • Personal Access Token. Paste a token with the repo scope and click Connect with PAT. You can create one in your GitHub account's developer settings.
  • GitHub Login. Sign in through GitHub's device flow. You first need a GitHub OAuth App. Under Integrations → GitHub Integration → GitHub Login, enter the OAuth App's Client ID. No client secret is needed. Then click Sign in with GitHub and follow the code prompt.

You can also choose where new repositories are created by default.

Jira​

To import Jira issues as tasks, enter the following in the Jira fields under Integrations:

  • Instance URL: the address of your Jira site.
  • Email: the email address of your Jira account.
  • API Token: an API token created for that account in your Atlassian account settings.

Jira is optional. Nothing else in the app depends on it.

Code quality (SonarCloud and Codacy)​

Both are optional. They are under Integrations → Code Quality.

  • Sonar API Key: a SonarCloud token. It is passed to agent runs as the Sonar key so that agents can run Sonar checks.
  • Codacy API Key: a Codacy account token. It is passed to agent runs as the Codacy account token so that agents can run Codacy checks.

If you do not save these, agent runs still work. Code-quality checks just cannot run.

Semantic search and embeddings​

Semantic search and related features compute embeddings with a model running on your own machine through Ollama. They need no API key. You need Ollama installed and running. Check its status under Diagnostics.

Telemetry and tracing (optional)​

Telemetry is consent-based. Under Data & Privacy you can find the OpenTelemetry consent controls. The license key field for the telemetry endpoint only appears in builds that include an endpoint, and saving that key is only needed for those builds.

Agent tracing can send traces to an OTLP endpoint you provide. Its settings are also under Data & Privacy.

Custom secrets and MCP servers​

Under AI & Tools → Custom Secrets you can store your own named values, for example for an MCP server that needs a token. Only add secrets that a server or tool you use actually requires.

Cloud sync​

CloudSync uses a CrewDeck cloud sync account. You sign in from the CloudSync tab. It is not a third-party provider key.

How your keys are stored​

  • Keys are stored with the operating system's secure storage through Electron's safe storage. On macOS this is the Keychain, on Windows it is DPAPI and on Linux it is libsecret or KWallet.
  • If the operating system's secure storage is not available, CrewDeck falls back to an encrypted file on your machine. In that case the settings screen shows a red warning that the security level is reduced.
  • Keys are not written to the app's logs. Error messages from the OpenAI and Anthropic clients are replaced with generic messages so that keys are not repeated back to you.
  • Removing a key with its Remove API Key button deletes the stored value.

Troubleshooting​

SymptomLikely causeFix
A Codex run says the OpenAI API key is not configuredNeither a device sign-in nor an API key is savedSign in under AI & Tools → Codex Authentication, or save an OpenAI key under Integrations → LLM Provider
A Codex run says device authentication is configured but the runner is unavailableThe Codex CLI is not installed or not signed inInstall the Codex CLI, sign in again with Device Code, or save an OpenAI API key
Podcast audio failsNo OpenAI API key savedSave an OpenAI key under Integrations → LLM Provider
Voice dictation does not record or transcribeNo OpenAI API key savedSave an OpenAI key under Integrations → LLM Provider
Cannot select xAI as the active providerxAI is not available yetChoose Anthropic, OpenAI or Google Gemini
GitHub features fail after a token changeThe token is missing the repo scope or has expiredCreate a new token with repo scope and connect again
The Settings screen shows reduced securityOperating system secure storage is unavailableFix the system keychain or secret service, then save your keys again
